# TIA-Portal-Teamcenter-Operationen

**Sprache:** [English](TEAMCENTER_OPERATIONS_SUMMARY.md) · Deutsch

## Unterstützungsstatus

Die aktuelle Oberfläche für den Projektlebenszyklus arbeitet mit gewöhnlichen lokalen Projektpfaden. Sie umfasst keine Teamcenter-Dienst-, Speicher-, Managed-Project- oder Teamcenter-Verbindungsobjekte.

## Aktuelle Grenzen

Die aktuelle Oberfläche bietet nicht:

- Erkennung oder Verfügbarkeitsprüfung von Teamcenter-Diensten.
- Auflistung oder Verwaltung von Teamcenter-Speichern.
- Zuordnung von Managed Projects oder einen Teamcenter-gestützten Projektlebenszyklus.
- Teamcenter-spezifische Abläufe für Verbindung, Authentifizierung oder Ausnahmen.

Für lokale Projektoperationen siehe [PROJECT_OPERATIONS_SUMMARY.md](PROJECT_OPERATIONS_SUMMARY.de.md).
