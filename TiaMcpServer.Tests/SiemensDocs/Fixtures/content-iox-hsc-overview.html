While this package remains fully functional and supported within the 2510 release, it has been superseded by @ax-as/s7-highspeedcounter-lib starting with the 2610 release. If you want to upgrade to 2610, please see migration guide at the 2610 breaking changes documentation.

This package contains High-Speed Counter function implementations.

Note

This library requires the PLC to activate the high-speed counter feature. The hardware configuration should be configured and downloaded properly in advance.
